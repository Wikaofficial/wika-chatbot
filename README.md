# Wika Private + Cloudflare Workers AI

Gotowy projekt strony z chatbotem.

## Zawartość

- `public/` — aktualna strona Wika, zdjęcia, CSS i czat w przeglądarce
- `src/index.js` — Worker oraz endpoint `/api/chat`
- `wrangler.jsonc` — statyczne assets i binding Workers AI `AI`
- `DEPLOY.md` — instrukcja wdrożenia

## Styl czatu

- naturalny i odważniejszy flirt,
- krótkie odpowiedzi,
- język dopasowany do rozmówcy,
- naturalne kierowanie do private access,
- jasne oznaczenie automatycznego asystenta,
- rozmowy wyłącznie 18+.
